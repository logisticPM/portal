RoadmapOCAP “export my records.” The Exports bucket is provisioned (and IAM-wired) so a future route can hand a First Nation, Inuit, or Métis organization a short-lived signed URL to download their own data on demand — the Ownership + Access half of OCAP. The infrastructure is in place; the export flow is the next build, so enabling it needs no architecture change.
OCAP data governance: personal and supplier data (RAP uploads, extractions, commitments, notifications) stays at rest in ca-central-1. AWS publishes no Canadian Bedrock geography, so Bedrock / BDA / Textract inference geo-routes to us-east-1 via the us. inference profile — data is governed in Canada while compute runs in the US. The public LegalCases corpus lives in us-east-1 and is read cross-region.
